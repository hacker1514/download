Creating a GitHub Personal Access Token (Classic)

"K Drive" requires a GitHub Personal Access Token (Classic). GitHub no longer supports account passwords for Git operations.

Steps

1. Sign in to GitHub.
2. Go to Profile → Settings → Developer settings → Personal access tokens → Tokens (classic).
3. Click Generate new token (classic).
4. Enter a Note (for example: "K Drive").
5. Choose an Expiration (or No expiration if preferred).
6. Under Scopes, select repo.
7. Click Generate token.
8. Copy the token immediately. GitHub will only show it once.

During K Drive setup, enter:

- GitHub Username: Your GitHub username.
- GitHub Personal Access Token: Paste the generated token.

«Important: Do not enter your GitHub account password. Use the Personal Access Token instead.»
